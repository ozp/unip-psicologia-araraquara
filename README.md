# UNIP Araraquara — Psicologia · Extensão Universitária

Este repositório é o **local de publicação dos infográficos semestrais de extensão universitária** do curso de Psicologia da Universidade Paulista (UNIP), Campus Araraquara.

A extensão é componente curricular obrigatório do curso (Resolução CNE/CES nº 7/2018 — no mínimo 10% da carga horária). A cada semestre, os grupos de estudantes registram suas atividades por meio de formulários, e a coordenação consolida os dados em um **infográfico público** que documenta as ações, o alcance e os resultados do semestre.

## Estrutura

```
extensao/
├── 2025-1/    # Infográfico 2025-1 (primeiro semestre do processo)
├── 2025-2/    # Infográfico 2025-2
├── 2026-1/    # Infográfico 2026-1
└── ...
```

Cada semestre possui um `index.html` com o infográfico (visualizável pelo GitHub Pages) e os respectivos assets em `infografico_imagens/`.

## Conteúdo típico do infográfico

- Panorama do semestre (grupos, estudantes, professores, participantes)
- Produções por turma (atividades, disciplinas vinculadas, alcance)
- Modalidades, públicos e temas abordados
- Vozes da extensão (relatos de estudantes)
- Impacto consolidado e avaliação
